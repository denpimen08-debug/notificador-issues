# 🔔 Notificador de Issues

Sistema de notificaciones para realizar el seguimiento de comentarios en Issues de GitHub, orientado a los repositorios académicos de la **Facultad Nacional de Ingeniería (FNI), Carrera de Sistemas Informáticos**.

## 📌 Descripción

El proyecto tiene como objetivo facilitar el seguimiento de la actividad en los Issues de GitHub mediante notificaciones por correo electrónico cuando se registran nuevos comentarios.

La finalidad es centralizar las notificaciones y ayudar a los colaboradores a mantenerse informados sobre la actividad de los repositorios sin tener que revisar cada uno manualmente.

## 🎯 Objetivos

- Detectar nuevos comentarios en los Issues de los repositorios configurados.
- Enviar notificaciones al correo electrónico correspondiente.
- Identificar el repositorio, el número del Issue, su título y el comentario recibido.
- Facilitar el seguimiento y la colaboración en los proyectos académicos.

## 🏛️ Repositorios académicos

Este proyecto está relacionado con la organización **SIS-INF**, correspondiente a los repositorios académicos de la Carrera de Sistemas Informáticos.
